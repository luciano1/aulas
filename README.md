# Aulas de Programação

Hub de materiais, exercícios e projetos de apoio para aulas de programação, desenvolvimento web e fundamentos de software.

Este repositório reúne conteúdos usados em sala, exemplos práticos e projetos guiados. A proposta é organizar o aprendizado por trilhas, sempre com foco em prática, leitura de código e construção gradual de autonomia.

## Trilhas disponíveis

| Trilha | Conteúdo |
| --- | --- |
| HTML | Estrutura de páginas, textos, links, imagens, tabelas, formulários, semântica e boas práticas |
| JavaScript | Fundamentos, listas de exercícios, componentes, estado, localStorage e projetos web |
| Java | Fundamentos da linguagem, exercícios e programação orientada a objetos |
| PHP | Fundamentos, funções e materiais de apoio por turma/ano |
| Python | Revisão de lógica e primeiros scripts |
| Projetos | Aplicações práticas para consolidar os conceitos estudados |

## Como estudar

1. Escolha a trilha indicada em aula.
2. Leia os arquivos na ordem sugerida quando houver numeração.
3. Execute os exemplos localmente.
4. Resolva os exercícios antes de consultar soluções ou referências externas.
5. Evolua os projetos por etapas, registrando dúvidas e melhorias.

## Para estudantes

Use este repositório como material de apoio. O objetivo não é apenas copiar código, mas compreender a ideia por trás de cada exemplo, praticar pequenas alterações e construir projetos próprios a partir dos fundamentos.
